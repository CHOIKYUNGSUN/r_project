# R 타이핑 실습실

보건의료 데이터 분석 수업용 R 코드 따라 입력하기 실습 페이지입니다.
왼쪽 콘솔의 코드를 보고 오른쪽 입력창에 똑같이 입력하면 복사 버튼이 켜지고, RStudio에 붙여넣어 실행한 뒤 예상 결과와 비교합니다.

- 접속 주소: https://choikyungsun.github.io/r_project/
- 구성: 제1장 ~ 제4장 (`index.html` 한 파일)
- 진행 상황은 각 학생 브라우저에 저장됩니다.

## 관리자 로그인
관리자로 로그인하면 원본 소스를 복사하고 입력창에 붙여넣을 수 있습니다.
공개 저장소이므로 비밀번호 원문 대신 `SHA-256("아이디:비밀번호")` 값만 `index.html`의 `ADMIN_HASH`에 들어 있습니다.
비밀번호를 바꾸려면 새 값의 SHA-256을 계산해 `ADMIN_HASH`를 교체하세요.
